# APLICAÇÃO WEB - GESTÃO DE EMPRESA PRESTADORA DE SERVIÇOS RELACIONADOS A AR-CONDICIONADO

Aplicação Web para uso interno de empresa prestadoras de serviços relacionados à ar-condicionado, desenvolvida com HTML, CSS e PHP.


## Principais funcionalidades
- CRUD (clientes, serviços, ordens)
- Emissão de Nota de serviço em '.pdf'


## Visuais
- elementos visuais com CSS3


## Aprendizado durante o projeto
- uso de diferentes elementos HTML para o desenvolvimento do menu, títulos, formulário e etc.
- criação de formulário de preenchimento
